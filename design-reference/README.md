# Teezy design reference

One HTML mock per screen at 390x844, exported from the Teezy design canvas.
Open any file's markup to read exact sizes, colors, spacing, copy and mock data.
The <script type="text/x-dc"> block at the bottom of each file holds that screen's mock data and small state logic.
They depend on the design tool's runtime, so they won't render on their own in a browser: read them as a spec.
